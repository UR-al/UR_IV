# 스튜디오 LoRA 선택 창 (LoRA 브라우저) 설계

작성 2026-11-11 · 대상: ComfyUI 팩 `comfy_custom_nodes/ai_studio_forge_parity` (다음 버전 1.19.0)

## 1. 왜 만드나

- LoRA 이름이 너무 길어져 스튜디오 LoRA 칸에서 거의 다 잘린다. D:\LoRA 에 871개, 경로 길이 중앙값 76자·최대 117자
  (예: `LoKr/묵밥 (@Bjunbae)/@bjunbae_2.9b_lokr_came_b10_2e06_fp16/@bjunbae_2.9b_lokr_came_b10_2e06_fp16-000014.safetensors`).
  런 이름이 폴더와 파일에 두 번 들어가고, 기본 드롭다운이 뒤를 잘라 **정작 중요한 에폭이 안 보인다.**
- 사용자는 ComfyUI LoRA Manager 같은 창을 원한다(검색·미리보기·폴더 묶음). 그 노드는 GPL-3.0 이라 사용자 규칙
  ("팩에 제3자 GPL 코드 복사 금지")상 코드는 못 가져오고, **기능과 사용감만 참고해 새로 짠다**(XYZ 를 Forge 동작만 보고
  새로 짠 것과 같은 방식). 조사는 LoRA Manager 의 README·위키·릴리스 노트만 읽었고 소스는 열지 않았다.
- 사용자 결정(11-11): **LoRA 카드의 "+ LoRA" 를 누르면 이 창이 뜬다.**

## 2. 목표 · 비목표 · 실패 조건

**목표**
- "+ LoRA" → 창에서 골라 새 줄 추가. 이미 있는 줄의 이름을 누르면 같은 창이 열려 그 줄을 바꾼다.
- 패널 어디서나 **짧은 이름**(`묵밥 · @bjunbae fp16 · e14`), 마우스를 올리면 전체 경로.
- 창 안: 검색, 작가(그룹)·런 폴더 묶음, 런 하나 = 카드 하나 + 에폭 고르기, **그 에폭의 학습 샘플 4장 미리보기**,
  트리거 단어와 학습 정보, 즐겨찾기·최근 사용, 정렬, 키보드 조작.
- 로컬 자료만으로 동작한다(오프라인). 네트워크 없이 871개를 빠르게 연다.

**비목표 (1차에서 안 함, 필요하면 나중에)**
- Civitai·HF 메타데이터 받기, 모델 다운로드, 업데이트 확인, 레시피, 중복 찾기, 통계 페이지.
- 파일 옮기기·이름 바꾸기·지우기 같은 파일 작업, 메타데이터 고쳐 쓰기. **D:\LoRA 에는 아무것도 쓰지 않는다.**
- 체크포인트·임베딩 탭(LoRA 만).

**실패 조건 (이러면 잘못 만든 것)**
- 저장값이 바뀌어 기존 워크플로·EXIF 재현·`<lora:이름:세기>` 태그·보드 연결이 깨진다. → 저장값은 지금처럼 파일 stem.
- 패널 첫 로딩이 느려진다(색인을 패널 열 때 통째로 만들기 등).
- GPL 코드나 그 CSS·아이콘이 섞인다.

## 3. 사용 흐름

1. LoRA 카드에서 **+ LoRA** → 창이 패널 위로 크게 뜬다(화면 폭 95%·최대 1200px, 패널 폭과 무관).
2. 검색칸에 바로 입력된다. `bjun 14` → 묵밥 런의 e14. 토큰은 AND, 대소문자·`_`/공백 무시.
3. 카드를 고르면 오른쪽 상세 칸에 그 런의 **에폭 칩**(e1 … e15, 보드에서 별 찍은 에폭은 ★)과 선택 에폭의 샘플 4장.
4. **마우스만으로 끝까지 된다(사용자 11-11: "단축키도 좋은데 마우스만 가지고 할 수 있으면 편할 듯").**
   - 카드마다 **"+ e15 최종 추가"** 버튼(고른 카드면 상세 칸에서 고른 에폭, 아니면 마지막 에폭). 상세 칸에도 "+ e14 추가" 큰 버튼.
   - 누를 때마다 **패널에 바로 한 줄 들어가고**, 창 아래 **"이번에 추가" 줄**에 칩으로 쌓인다(✕ = 그 줄을 패널에서 빼기).
     아래 오른쪽 **"완료 · N개 추가됨"** 으로 닫는다. Esc·✕·바깥으로 닫아도 이미 넣은 줄은 남는다.
   - 머리줄 **"추가하면 닫기" 켬/끔**(기본 끔, 마지막 값 기억): 켜면 한 번 추가하고 바로 닫힌다.
   - 세기는 −/+ 버튼(0.05)과 슬라이더(0~2) + 숫자. 키보드(Enter·Shift+Enter 등)는 보조로 남는다.
5. 줄의 이름을 누르면 "바꾸기" 모드로 열려 현재 LoRA·에폭이 선택된 채 시작한다(버튼 글자는 "이걸로 바꾸기", 바꾸면 닫힘).
6. Esc 로 닫기(팩의 모달 순서 규칙을 따른다).
7. 시안: https://claude.ai/artifact/8RBPWX6BmQnYGfZveAkvkG (Main = 추가·바꾸기, Xyz = XYZ 모드, Panel = 패널 칸 지금/바뀐 뒤).

## 5. 짧은 이름 규칙 (JS 순수 함수 하나, 패널·XYZ·자동완성 힌트가 같이 씀)

- 경로를 `알고리즘/그룹/런/파일` 로 본다. 파일 stem 의 `-0000NN` → `eNN`; 런 폴더 안의 `<런>.safetensors` → `최종`
  (색인에 `ss_num_epochs` 가 있으면 `최종 e15`).
- 런 이름에서 학습 설정 꼬리 `_<크기>_<알고>_<옵티>_b<N>_<lr>`(예: `_2.9b_lokr_came_b10_2e06`)를 떼어 배지로 옮기고,
  남는 꼬리(`fp16`, `wsd_fp16`)는 이름에 둔다 → `@bjunbae fp16`.
- 표시: `그룹 · 런 · 에폭`. 런 이름이 그룹과 같은 핸들이면 그룹은 생략. 옛 런(파일이 그룹 폴더 바로 아래)과
  `_downloaded/<이름>/<파일>` 도 같은 규칙으로 처리.
- 그래도 길면 **가운데를 줄이고**(…) 에폭은 항상 보이게.

## 6. 자료는 어디서

| 표시 | 출처 (우선순위) |
|---|---|
| 목록 | 기존 `GET /aistudio/studio/choices?kind=loras` (folder_paths) |
| 에폭·모델·알고리즘·날짜·스텝·데이터 폴더 | safetensors 머리말 `__metadata__` (`ss_epoch`, `ss_num_epochs`, `ss_sd_model_name`, `ss_network_args`, `ss_mixed_precision`, `modelspec.date`, `ss_dataset_dirs` …). 머리말만 읽는다(앞 8바이트 + JSON, 상한 둠) |
| 트리거 | ① 보드 `board_db.json` 의 `runs[런].trigger` ② `ss_tag_frequency` 에서 `@` 로 시작하는 가장 흔한 태그 ③ 없음 |
| 에폭 샘플 4장 | ① `UR\ANIMA\<런>\sample\<런>_e<6자리>_<번호>_*.png`(런 폴더는 D: 쪽 `move_log.jsonl` 의 src 로 찾음) ② 보드 `site\s\<런(@ 뺌)>\e<3자리>.webp`(4장 띠) ③ 없으면 자리표시 |
| 프롬프트 이름(불꽃 검사 등) | 보드 `runs[런].prompts[].label` |
| ★ 에폭 | 보드 `marks[런].stars` |

- **런 → 샘플 폴더 찾는 순서**: ① 그 런 폴더의 `move_log.jsonl` src(10개 런만 있음) ② `D:\LoRA\_manifest.jsonl` 의
  run 이름 → src(dst 는 알고리즘 폴더로 나누기 전 경로라 안 씀) ③ `UR\ANIMA\<런 이름>` 이 있으면 그것 ④ 없으면 자리표시.
  옛 런(에폭 파일이 그룹 폴더 바로 아래)은 파일 stem 에서 `-0000NN` 을 뗀 것을 런 이름으로 본다.
- **현실 (11-11 실측)**: 런 136개 중 C: 에 샘플이 남은 것 21개, 보드 띠 7개, **둘 다 없는 것 115개**(옛 3.8B·지운 샘플).
  → 미리보기 없는 런을 어떻게 할지는 10절 질문.
- 보드 `board_db.json` 은 Tailscale 보드 서버(8766)가 직접 쓰는 파일이라 로컬 파일이 곧 최신이다(별 찍기 즉시 반영).
  다만 fp16 이후 런 8개만 들어 있어, 없는 런은 ★·프롬프트 이름 없이 보인다.
- 다운로드 LoRA 는 `<알고리즘>\_downloaded\<이름>\<파일>`(Full·LoCon·LoRA 아래에 있음): 폴더로 "다운로드" 배지,
  머리말 `__metadata__` 가 없으면 "정보 없음". 그림은 자리표시.
- 위 경로(UR\ANIMA, 보드 폴더)는 기본값을 두고 팩의 새 설정 파일(`user/default/ai_studio/lora_browser.json`)에서 바꿀 수
  있게 한다(코드에 박지 않음). 팩에는 아직 설정 파일·모달 순서 규칙이 없으므로 이 창에 필요한 만큼 새로 만든다
  (Esc 는 이 창이 맨 위일 때만, 열린 lightbox 가 있으면 그쪽 먼저).
- 지금 LoRA 는 전부 D:\LoRA 에 있고 이름(stem) 중복이 없다(11-11 확인) → stem 저장 방식 유지에 문제 없음.

## 7. 구조

**Python (새 모듈, Qt·ComfyUI 와 분리된 순수 로직 + 얇은 라우트)**
- `lora_index.py`: 목록을 받아 항목별 {경로, stem, 크기, mtime, 머리말 요약, 런·에폭·그룹, 트리거} 를 만든다.
  색인 캐시는 ComfyUI user 폴더(`user/default/ai_studio/lora_index.json`)에 (경로, 크기, mtime) 키로 저장 → 두 번째부터 즉시.
  D:\LoRA(exFAT)는 폴더 mtime 이 안 바뀌므로 파일 단위로 비교하고, 창의 "다시 읽기"가 강제 갱신.
- `lora_samples.py`: 위 표의 순서대로 에폭 샘플을 찾고, 썸네일(긴 변 384px webp)을 user 폴더 캐시에 만들어 둔다.
- 라우트(`studio_routes.py` 에 추가, 접두 `/aistudio/studio/loras`): `GET index`, `GET detail?name=`,
  `GET thumb?name=&epoch=&i=`(만든 썸네일만, 경로는 색인에 있는 것만 허용), `GET/POST prefs`(즐겨찾기·최근).
- 즐겨찾기·최근·마지막 정렬은 `user/default/ai_studio/lora_prefs.json`(브라우저가 바뀌어도 유지).

**JS (새 파일들, 큰 파일에 덧붙이지 않음)**
- `lora_names.js`: 짧은 이름·검색 일치·그룹 묶기·정렬 — 순수 함수, `js_tests/lora_names.test.mjs`.
- `lora_browser.js`: 창(오버레이, `role=dialog`, 포커스 가두기, 가상 스크롤, 키보드).
- `panel_view.js` `loraCard`: 줄의 `select` → 짧은 이름 버튼(title=전체 경로), "+ LoRA" → 창 열기. 저장 형태
  `{on, name, strength}` 는 그대로.

## 10. 사용자 결정 (11-11, 네 가지 모두 추천안)

1. **XYZ 의 LoRA 축도 같은 창을 쓴다.** "XYZ 모드"로 열리면 런을 고르고 에폭 칩을 여러 개 체크 → 체크한 에폭이 XYZ LoRA 줄
   (`rows[].lora`)로 들어간다. 기준 줄·`epoch_mode` 같은 기존 XYZ 구조는 그대로.
2. **트리거 "넣기"는 작가 칸**(`prompt_artist`)에 덧붙인다(이미 있으면 다시 넣지 않음, 쉼표 구분).
3. **계열별로 거른다.** 기본 목록 = 지금 체크포인트 계열(팩의 `unetFamily`: 2.9b/3.8b/base/moss/krea2) + 계열을 모르는 것.
   다른 계열로 확실한 것(3.8B·base·MOSS 런 등)은 "모든 모델"을 켜야 보인다. **base 로 학습한 LoRA 도 2.9B 에서는 숨긴다.**
   계열 판정: 머리말 `ss_sd_model_name`·`modelspec.architecture`·`ss_base_model_version`, 없으면 런 이름의 `_2.9b_`·`_3.8b_`,
   그래도 없으면 "모름".
4. **미리보기는 자동 + 직접 지정.** 순서: ① 직접 지정한 그림 ② 그 에폭의 학습 샘플(6절) ③ **출력 그림 중 EXIF(인포텍스트)에
   그 LoRA(`<lora:stem:`)가 든 가장 최근 그림** ④ 자리표시.
   - ③: ComfyUI output 폴더 그림의 인포텍스트를 읽어 LoRA → 최근 그림 표를 만든다. (경로, mtime) 캐시로 새 그림만 읽고,
     창을 열 때 백그라운드로 갱신(패널 첫 로딩을 막지 않음).
   - ①: 스튜디오 갤러리·라이트박스의 그림에 "LoRA 미리보기로" 메뉴 → 그 그림에 든 LoRA 중 고르면 썸네일을 user 폴더
     캐시에 저장(D:\LoRA 에는 안 씀). 창의 상세 칸에서 "지정 해제" 가능.
   - 직접 지정·자동은 **런 단위**(대표 그림)로 둔다; 에폭 칩의 4장은 학습 샘플이 있을 때만.
