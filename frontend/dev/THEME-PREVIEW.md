# 테마 UI 미리보기

이 미리보기는 실제 Vue 화면을 **가상 데이터와 메모리 전용 브릿지**로 보여준다. 실제 이미지 생성, Forge/ComfyUI 실행, 개인 파일 접근 및 설정 저장을 위한 화면이 아니다. 여기서 바꾼 설정은 실제 앱에 저장되지 않는다.

사용자가 다시 열어볼 수 있도록 남겨두는 개발 도구다. 일회성 점검 파일로 간주하여 삭제하지 않는다. 제품 앱의 진입점이나 배포 빌드에는 포함하지 않는다.

## 실행

1. 이 폴더의 `start-theme-preview.cmd`를 더블클릭한다.
2. 브라우저에서 <http://127.0.0.1:5174/dev/theme-audit.html>을 연다. 시작 파일은 기본 브라우저도 자동으로 연다.
3. 미리보기를 사용하는 동안 서버 창을 켜둔다. 종료하려면 서버 창에서 Ctrl+C를 누른다.

이미 서버가 실행 중이면 시작 파일을 다시 실행할 필요 없이 주소만 연다. 포트 5174가 사용 중이라는 오류가 나면 먼저 기존 미리보기 주소를 확인한다. 다른 프로그램이 사용하는 포트를 임의로 종료하지 않는다.

직접 실행할 때는 프로젝트 루트 기준:

```powershell
cd frontend
npm run dev -- --host 127.0.0.1 --port 5174 --strictPort
```

`C:/.../frontend/dev/theme-audit.html` 또는 `file:///...`는 실행 주소가 아니다. Vue 소스와 모듈을 처리하는 Vite 개발 서버가 필요하다. 파일을 직접 열었을 때는 실행 안내만 표시된다. 이 주소는 해당 PC에서만 열린다.

## 점검 범위

- 실제 Vue App과 탭, 테마 변경 및 합성 데이터 화면을 확인할 수 있다.
- 페이지 새로고침으로 미리보기의 변경 사항을 초기화한다.
- Python 네이티브 종료창·트레이·파일 선택창이나 실제 백엔드 생성은 이 브라우저 미리보기로 검증할 수 없다.
- 시작/로딩 오류가 보이면 오류 내용을 확인한다. 채팅을 재선택하거나 HTML 파일을 반복 클릭하는 것은 서버 실행을 대신하지 않는다.

## README 스크린샷 모드

주소 끝에 `?readme` 를 붙이면(<http://127.0.0.1:5174/dev/theme-audit.html?readme>) 문구 없는 합성 그림 6장,
크기·시드가 있는 생성 결과, 여러 줄의 검색 결과, 와일드카드 샘플을 넣고 모의 동작 알림을 띄우지 않는다.
README 의 `docs/images/readme/*.png` 는 이 모드를 헤드리스 Chrome 으로 찍은 것이다. 다시 찍을 때는 개발 서버를 띄운 뒤
저장소 루트에서 `venv\Scripts\python.exe tools\capture_readme_screens.py` 를 실행한다(기본 주소는 `npm run dev` 의 5173 포트).
